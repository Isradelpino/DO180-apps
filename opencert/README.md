# openCert – Repositorio de ontología y ejemplos

Este repositorio contiene la ontología **openCert** (RDF/Turtle) y ejemplos de **Solution Building Blocks (SBB)** para el cumplimiento del AI Act.

## Contenido

- `opencert.ttl` – Ontología openCert (basada en W3C DPV)
- `examples/` – Ejemplos de SBB (CHG, BiasInjector)
