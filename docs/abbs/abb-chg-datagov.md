# Data Governance for River Basin Authorities (based on ISO 33000) (`ABB-CHG-DATAGOV-v1.0`)

## Description
Capability to manage data quality, lineage, lifecycle, and provenance for AI systems in critical water infrastructure, aligned with Art. 10 of the AI Act and AESIA Guide 04.

## AI Act Context
- **High-risk system type:** eu-aiact:HighRiskAISystem-AnnexIII-2
- **Risk level:** eu-aiact:RiskLevelHigh
- **Articles addressed:** Art.10, Art.12

## Sector Purposes
sector-infra:CriticalWaterManagement

## Related Standards
ISO 33000, ISO 8000

## Maturity Levels (ISO 33020)
| Level | Description |
|-------|-------------|
| 1 | Initial – ad-hoc data management |
| 2 | Managed – basic data quality checks, manual lineage |
| 3 | Established – standardized data governance policy |
| 4 | Predictable – quantitative metrics, automated lineage |
| 5 | Optimizing – proactive, AI-driven governance |

## Reusability
- **Target organization type:** RiverBasinAuthority
- **Adaptation required:** none
